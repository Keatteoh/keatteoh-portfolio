GreenSlate: product design and systems

GreenSlate is an enterprise resource planning platform built for media production, with tools for accounting, payroll, approval flows, team management, and business intelligence. I worked on many projects there, as both product designer and feature owner.

Project 1A cross-team design system

As the web app added features, its library of components and design conventions grew with it. The application had accumulated design and technical debt, and the best way to tackle it was a cross-team design system.

  • Designed a framework for the system, so it could inform every team
  • Ran an application-wide UI audit to capture every existing component, spot inconsistencies, and normalize UI conventions
  • Built the system with development (codebase), marketing (brand guidelines) and design, so it works for everyone

Project 2Enhancing file attachments

Users needed to attach files to individual transaction lines, rather than to one general repository for all transactions.

  • Interviewed users and subject matter experts on how attachments are used to build a "digital envelope" for expense reconciliation
  • Ran a competitive analysis of Expensify's UI and UX for best practices
  • Audited the existing file upload process and outlined the changes needed
  • Prototyped the new UI for desktop and mobile, iterating on stakeholder feedback

Project 3User personas

GreenSlate serves many kinds of users, and the team needed a shared definition of them to reference when building features.

  • Interviewed subject matter experts on the roles people hold on productions, which vary by scale and media type
  • Interviewed users about their daily workflow, their comfort with technology, accounting, and production, and their favorite app and film
  • Compiled the findings into a master PDF shared with the team

Project 4Migrating accounting reports

Moving the Accounting Reports feature from GreenSlate's legacy software to the new web application.

  • Audited each report type and its filter parameters
  • Documented the findings as the master spec, with flowcharts and spreadsheets
  • Updated or removed redundant filters to simplify the experience
  • Prototyped the new UI, iterating on stakeholder feedback
  • Oversaw QA and user testing for a seamless transition for new and existing users

Project 5Integrating PEX prepaid cards

A card management tool, built with a partner company.

  • Ran a competitive analysis of the PEX portal and other prepaid card services
  • Worked with stakeholders to define the MVP for adoption, and a roadmap for later enhancements
  • Documented user flows, workflows, and user stories, then prototyped the main and adjacent pages
  • Oversaw testing in a sandbox environment to ensure data integrity
  • Worked with client support to move clients from the legacy import method to the new API

Project 6Incentives dashboard

A dashboard for the accounting team to track, manage, and share tax credit incentives with clients.

  • Interviewed subject matter experts on tax credit applications, and mapped the submission and processing workflows
  • Prototyped the incentives dashboard and creation page, and reviewed them with stakeholders
  • Ran testing with accountants to keep improving the experience

Project 7Tax documents and adoption

A feature for users to access their annual tax documents, and an effort to move users from paper to digital.

  • Interviewed experts on the tax document workflow and the legal requirements for sensitive documents
  • Prototyped the page and defined the onboarding workflow, iterating on stakeholder feedback
  • Documented the flows for users opting in to digital tax documents
  • Worked with client support to import every client's tax documents into the app
  • Led the cross-department effort to opt existing and new users in to digital documents

Project 8Reorganizing the sitemap

The navigation menu was growing quickly with new features, and needed a new hierarchy and categories.

  • Defined the application's sitemap through an audit
  • Consulted subject matter experts on feature priorities
  • Grouped features by production role, splitting them into company-level and project-level features
  • Defined breadcrumb paths to help users move around the app
  • Prototyped the new navigation and presented it to stakeholders
